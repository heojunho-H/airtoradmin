# 구글 광고 측정 — 대수별 전환값 · 향상된 전환 · 계약 성공 업로드 (2026-11-12)

## 흐름

1. **홈페이지 문의 폼**(별도 비공개 저장소)
   - 의뢰 대수 구간으로 문의 1건의 기대가치(공급가액)를 계산해 '문의완료' 전환 값으로 보낸다.
   - 이메일·전화를 구글 태그 `user_data` 로 넘긴다(구글 태그가 해시).
   - 2026-11-12 사용자 결정으로 동의 체크박스 없이 모든 문의에 적용한다. 국외 이전 고지는 개인정보 처리방침 제7조.
2. **CRM 딜 저장**
   - `functions/api/deals.ts` 프록시가 PHP 응답의 `transition:"won"` 을 보면 D1 `ads_deal_won` 에 처음 계약된 시각을 남긴다.
   - 프로젝트 `created_at` 은 운영 DB 에서 비어 있어 쓰지 않는다.
3. **업로드 피드** `functions/api/ads_conversions.ts` (+ `functions/_lib/ads-feed.ts`)
   - 대상 딜(모두 해당)
     - 지금 '계약 성공' 상태다.
     - 계약 시각이 최근 90일 안이다.
       - 계약 시각 기록이 없는 딜(기록을 시작한 2026-11-12 배포 전 계약 등)은 **문의 등록일 23:59:59**를 계약 시각으로 쓴다(2026-11-13 사용자 결정). 구글 HTTPS 연결은 데이터 행이 1개 이상 있어야 만들어지는데, 그때 기록된 계약이 없었다. 첫 적용 때 최근 90일 20건이 이렇게 들어갔다.
     - 요청사항에 `[광고측정제외]` 가 없다. 고객이 거부를 요청하면 직원이 딜 요청사항에 붙인다(처리방침 제7조 거부 방법).
     - 이메일이나 전화가 있다.
   - CSV 열
     - `Email`, `Phone Number`: SHA-256 해시
     - `Conversion Name` = `계약 성공(CRM)`
     - `Conversion Time` = 계약 시각 `yyyy-MM-dd HH:mm:ss+0900`(기록이 없으면 문의 등록일 `23:59:59`)
     - `Conversion Value` = 공급가액(프로젝트 `netRevenue`, 없으면 견적 − 부가세)
     - `Conversion Currency` = `KRW`
     - `Order ID` = `deal-<id>`(반복 업로드해도 중복이 생기지 않는다)
   - `GET`: Basic 인증. 구글 데이터 관리 도구 HTTPS 연결이 매일 가져간다.
   - `POST {pin, userName, format}`: 관리자 PIN. 설정 > '구글 광고 계약 업로드' 카드(현황 숫자, 수동 백업 파일)에서 쓴다.

## 환경변수 (Cloudflare Pages > Settings > Variables, Production·Encrypt)

| 이름 | 쓰임 |
|---|---|
| `ADS_FEED_USER` | 데이터 관리 도구 HTTPS 연결 사용자 이름 |
| `ADS_FEED_PASS` | 같은 연결 비밀번호(긴 무작위 값) |

- 둘 중 하나라도 없으면 `GET` 은 503 을 돌려준다.
- 값은 저장소에 두지 않는다.
- D1 바인딩 `AI_DB` 는 기존 것을 쓴다. 표 `ads_deal_won` 은 코드가 처음 쓸 때 만든다(`d1/migrations/0004_ads_deal_won.sql`).

## 구글 광고 쪽 설정

- '문의완료': 값은 '각 전환에 다른 값 사용'이다(기본값은 수량 미상 구간 값).
- 향상된 전환: 지금은 구글 태그 '자동 감지'(이메일만). '코드'(인페이지 `user_data`)로 바꾸면 전화까지 넘어간다 — 태그 관리자 권한 필요.
- '리드 확보용 향상된 전환' 사용 설정을 켠다.
- 오프라인 전환 액션 `계약 성공(CRM)` (2026-11-12 만듦)
  - 클릭에서 가져오기, 리드용 향상된 전환
  - 카테고리 '전환 고객', 값은 업로드 값(비면 ₩1,800,000 — 계약 공급가 중앙값), 횟수 1회, 클릭 기간 90일, 데이터 기반 기여
  - **보조 액션**이라 입찰에는 아직 쓰지 않는다. 새로 만들면 구글이 기본 목표에 넣어 기본 액션으로 잡으니, 만든 직후 설정에서 보조로 바꾼다.
- 데이터 관리 도구 > HTTPS > 전환수 > 오프라인 전환
  - URL `https://airtoradmin.co.kr/api/ads_conversions.csv`
    - 구글 HTTPS 연결은 주소가 `.csv`·`.tsv` 로 끝나야 받는다("파일 형식을 읽을 수 없습니다"). `.csv` 주소는 `functions/api/ads_conversions.csv.ts` 가 같은 GET 을 그대로 연다(2026-11-13).
  - 사용자 이름·비밀번호는 위 환경변수와 같은 값
  - 매일 실행한다.

## 확인

- 인증 없이 `GET /api/ads_conversions` 와 `GET /api/ads_conversions.csv` 를 부르면 둘 다 401 이 나야 한다(503 이면 환경변수가 없거나 재배포 전).
- 설정 카드 '현황 보기'에서 볼 숫자
  - 계약 성공 딜
  - 계약 시각 기록(배포 뒤 계약부터)
  - 최근 90일 계약
  - 그중 제외 요청(`[광고측정제외]`)
  - 업로드 행
- 데이터 관리 도구 연결 상태와 실행 기록을 본다. 업로드 처리에는 24~48시간 걸린다.

## 되돌리기

- **피드만 멈출 때**: 데이터 관리 도구에서 연결을 일시중지하거나, 환경변수 `ADS_FEED_PASS` 를 지운다(503).
- **계약 시각 기록을 멈출 때**: `functions/api/deals.ts` 의 기록 블록을 되돌린다. 프록시 응답은 원래부터 바뀌지 않는다.
